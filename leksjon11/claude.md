# Instruks til Claude

Denne mappen inneholder undervisningsmateriale til leksjon 11 om tema testing og DevOps i emnet APP2000 Applikasjonsutvikling for web, som er et andreårsemne på et IT-studium ved et universitet. Studentene har til nå lært grunnleggende React og JavaScript, og grunnleggende om REST API med Express. Vi har brukt en enkel nettbutikk Hobbyhuset som "case", og vi har bygd opp en enkel frontend og backend for denne løsningen.

Leksjon 11 tar for seg testing og DevOps for webapplikasjoner. Vi skal blant annet se hvordan man kan bruke biblioteket mocha for å gjøre unit-testing og vi skal deploye et monorepo til Heroku.

## Steg 1: Sjekk eksisterende kode

Koden ble skrevet i fjor. Gå gjennom undermappene og sjekk opp koden er oppdatert og kjører. Gi beskjed om noe bør forbedres, eller om koden burde utvides med andre teknikker.

## Steg 2: Nytt utgangspunkt på undermappe nettbutikk-2026

Det er nå lagt til en ny undermappe nettbutikk-2026, som inneholder oppdatert kode for en nettbutikk med backend skrevet i Express, frontend med React og autentisering med Passport (strategi local).

Denne løsningen skal utvides med demokode som illustrerer teknikker relatert til testing og deployment, nærmere bestemt:

- Løsningen skal bli et monorepo som (enkelt) kan deployes til Heroku. README-filen på denne undermappen skal forklare hvordan dette gjøres.
- Løsningen skal utvides med eksempler på unit-tester med bruk av Supertest og Mocha.
- Løsningen skal også utvides med ende-til-ende-testing med Playwright.

## Steg 3: Lag ny PowerPoint på undermappe presentasjon.

Undermappe presentasjon inneholder to PowerPoint-er til bruk på forelesning, som tar for seg henholdsvis testing og DevOps. Lag en ny og oppdatert presentasjon som behandler begge temaer pr. 2026, som dekker de viktigste momentene fra de eksisterende presentasjonene, og som får fram hvordan testing og devops er gjort i den oppdaterte nettbutikken på undermappe nettbutikk-2026. Gi den nye presentasjonen et moderne og friskt design. Max antall slides: 40.
