# Oppdatert butikk-klient med Vite (butikk-klient-vite-2026)

Jeg lot koden fra 2025 ligge uendret, blant annet av hensyn til leksjonsvideoene.

Denne mappen inneholder en oppdatert 2026-versjon av frontend for nettbutikken med Vite.

Jeg tok utgangspunkt i den enkle Vite-klienten fra leksjon 5 og fulgte deretter oppskriftene på README-filene i butikk-klient-vite-0 og butikk-klient-vite-2, som blant annet installerer Tailwind.

## Kjøre applikasjonen

Åpne et terminalvindu i VS Code.

Hvis du jobber med hele APP2000-repoet i VS Code, må du først gå ned i riktig mappe:

```
cd leksjon06/butikk-klient-vite-2026
```

Deretter kan du installere og kjøre:

```
npm install
npm run dev
```

Åpne nettleseren på adresse http://localhost:5173 for å se resultatet.
