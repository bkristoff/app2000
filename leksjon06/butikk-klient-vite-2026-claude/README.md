# Oppdatert butikk-klient med Vite - stilet og forklart med hjelp fra Claude

Denne appen er laget fra butikk-klient-vite-2026 med en enkel prompt til Claude: "Gjør brukergrensesnittet mer profesjonelt ved å bruke Tailwind, men endre ikke funksjonaliteten."

Hvis du sammenligner de to mappene vil du se at eneste forskjellen (hvis Claude har holdt seg til instruksen) er at det er lagt til en del Tailwind-klasser i JSX-koden.

Claude fikk også beskjed om å bygge en nettside som forklarte koden, se fil kodeforklaring.html. Øverst på siden ser du promptet.

## Kjøre applikasjonen

Åpne et terminalvindu i VS Code.

Hvis du jobber med hele APP2000-repoet i VS Code, må du først gå ned i riktig mappe:

```
cd leksjon06/butikk-klient-vite-2026-claude
```

Deretter kan du installere og kjøre:

```
npm install
npm run dev
```

Åpne nettleseren på adresse http://localhost:5173 for å se resultatet.
